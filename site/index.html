Where it runs

A macOS app on Apple silicon. Each copy is a NixOS microVM with its own compositor, rendering on the Apple GPU.

What is inside a copy

Apps arrive from a shared Nix store, identical in every copy. Snapshots next freeze a copy at a checkpoint and start N copies from it.

How agents drive it

Over MCP: spawn · screenshot · click · type · exec · steer. Bring your own agent — its.computer is the computer, not the brain.

Where this goes · local first, cloud ready

Infrastructure for agents to operate the same apps and computers humans use.

Not AI versions of your apps. The same Chromium, Blender, Figma, terminal and files that already exist — an agent gets to operate them, and so do you.

today

Give an agent a computer.

Real apps, real files, on your Mac. You watch, steer, take the wheel. Nothing leaves your disk unless you send it.

next

Give agents reproducible computers.

The environment from a Nix flake, snapshots to fork from, the board to design the process once.

then

Run many — and check the work.

N copies, N agents, N scenarios. The same copies validate the result against the design, replay it on a PR, and flag what doesn't hold — you decide.

finally

Cloud ready.

A process moves to the cloud with an address of its own — alice.its.computer — and an inbox. Reach it from Claude, ChatGPT or mail; it speaks MCP and email. Nothing you design is published by default.
